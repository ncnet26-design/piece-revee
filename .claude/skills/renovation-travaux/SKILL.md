# Rénovation et estimation (module à venir)

## Méthode
- Lots dans l'ordre : dépose/démolition → réseaux (électricité, plomberie) → cloisons → sols → menuiseries → finitions.
- Quantités seulement à partir de dimensions connues (surface murs = périmètre × hauteur − ouvertures), marquées « estimées » sinon.
- Budget = fournitures + main-d'œuvre + livraison + pose + imprévus (10–15 % à afficher comme hypothèse), avec date, zone géographique et postes manquants.
- Questions à poser aux artisans ; planning indicatif.

## Risques à signaler
Amiante (bâti avant 1997), plomb (avant 1949), humidité, structure : **un mur n'est jamais déclaré non porteur sur la base d'une image**. Renvoyer vers Service-Public.fr pour les diagnostics et autorisations.
