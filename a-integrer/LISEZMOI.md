# Images à intégrer

Déposez ici vos images (JPG, PNG ou WebP, idéalement 1600 px de large ou plus).

Nommez chaque fichier par sa collection puis un mot libre, par exemple :

- `villas-terrasse-ibiza.jpg`
- `haussmann-salon-moulures.png`
- `hotels-suite-velours.jpg`

Collections : salons, haussmann, chambres, villas, hotels, bars, clubs, cuisines, bains, design.

Claude les vérifie, les optimise, les place dans Inspirations avec la mention « Image créée par IA »,
puis vide ce dossier.
